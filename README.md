# Mẹ và Sunny học Tiếng Anh

Website học tiếng Anh dành cho mẹ và bé qua những tình huống gần gũi hằng ngày.

## Nội dung

- 8 chủ đề mở hoàn toàn.
- 50 từ và 50 câu thực tế trong mỗi chủ đề.
- Phát âm tiếng Anh bằng giọng đọc của trình duyệt.
- Lưu tiến độ học trên thiết bị.
- Giao diện tương thích với điện thoại và máy tính.

## Chạy dự án

Mở `index.html` trực tiếp trong trình duyệt hoặc chạy bằng một máy chủ web tĩnh.

## Công nghệ

HTML, CSS và JavaScript thuần, không cần cài đặt thư viện.
